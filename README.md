# 祈愿灯 · 水月新境

> 祈愿灯系列第二主题版本 · v2.0.0  
> 对应分支：`shuiyue-new-realm`

[返回项目与版本总览](https://github.com/chloe6723/qiyuan-lantern/tree/main)

“水月新境”在第一版孔明灯许愿体验的基础上，加入江南山水、月相和莲花水灯。用户可以让愿望乘风入夜，也可以随水远行，并在祈愿簿中回望旧愿。

## 版本定位

- **项目名称：** 祈愿灯
- **版本名称：** 水月新境
- **版本号：** 2.0.0
- **对应分支：** `shuiyue-new-realm`
- **核心意象：** 水月、古塔、石桥、孔明灯、莲花灯
- **区别于初版：** 增加莲花灯、水面场景、动态月相以及愿望编辑和删除

## 主要功能

- 孔明灯与莲花灯两种祈愿方式
- 琥珀、赭红、象牙三种灯色
- 单击灯火查看愿望
- 长按并拖动已放飞或放流的灯
- 祈愿簿支持查看、修改和删除
- 修改愿望时不改变原始日期
- 浏览器本地保存愿望
- 江南雾山、古塔、石桥、夜河与乌篷船场景
- 240 帧纹理月相循环动画
- 莲花灯限定在安全水域，避开乌篷船
- 桌面端与移动端响应式适配
- 敦煌莲花和花草纹饰

## 数据说明

愿望保存在浏览器 `localStorage` 中。同一设备、同一浏览器再次打开时可以继续查看；清理浏览器数据、更换设备或浏览器后不会自动同步。
