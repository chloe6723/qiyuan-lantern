# 祈愿灯 · 水月新境

“水月新境”是祈愿灯的第二个主题版本。用户可以写下愿望，选择放飞孔明灯或将莲花灯放流至水面，并在祈愿簿中回望、修改或删除旧愿。

## 主要功能

- 孔明灯与莲花灯两种祈愿方式
- 三种灯色可选
- 单击灯火查看愿望
- 长按并拖动已放飞或放流的灯
- 祈愿簿支持查看、修改和删除；修改不改变原始日期
- 浏览器本地保存愿望
- 江南雾山、古塔、石桥、夜河与乌篷船场景
- 240 帧纹理月相循环动画
- 莲花灯限定在安全水域，避开乌篷船
- 桌面端与移动端响应式适配

## 本地运行

```bash
pnpm install
pnpm dev
```

## 数据说明

愿望保存在浏览器 `localStorage` 中。同一设备、同一浏览器再次打开时可以继续查看；清理浏览器数据、更换设备或浏览器后不会自动同步。
