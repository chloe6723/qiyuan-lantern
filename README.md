# 祈愿灯 v1

一款古风沉浸式许愿记录应用。写下一段心愿，选择祈愿灯样式，将它放飞到夜空；日后可点击灯火回望当时的愿望，也可在「祈愿簿」中按时间浏览。

## 第一版功能

- 写下并放飞孔明灯愿望
- 三种灯色：琥珀、赭红、象牙
- 浏览器本地保存，刷新后仍可恢复
- 点击夜空中的灯回顾愿望
- 「祈愿簿」集中查看全部记录
- 长按已放飞的灯并拖动位置
- 桌面端与移动端适配

## 技术栈

- React 19 + TypeScript
- Vinext / Vite
- Tailwind CSS + shadcn/ui
- LocalStorage 本地持久化

## 本地运行

```bash
pnpm install
pnpm dev
```

构建生产版本：

```bash
pnpm build
```

## 说明

本仓库固定为「祈愿灯」第一版，不包含后续「水月新境」中的莲花灯、月相动画与新版篆刻 Logo。
